# MK.TECH site (GitHub Pages + browser admin)

Upload all files in this folder to a public GitHub repository, turn on GitHub Pages, then manage content at /admin.html with a GitHub token.

Files: index.html, style.css, config.js, script.js (public site) | admin.html, admin.js (admin) | data.json (live content: projects and leaders).
Edit email, divisions and capabilities in config.js (pencil icon on GitHub). data.json overrides projects and leaders.
Security: only someone with a token that can write to the repository can publish. Never share the token. The repository must be public on the free plan.
